# Cloud Cost Controls

## Objective

The objective is to minimize unnecessary cloud spending
while maintaining the required lab environment.

## Cost Control Measures

- Create only required resources.
- Stop unused compute resources.
- Delete temporary resources.
- Monitor resource usage.
- Configure budgets and alerts where available.
- Prefer local labs when cloud resources are unnecessary.

## Resource Cleanup

After completing a cloud lab:

1. Review running resources.
2. Stop unnecessary compute.
3. Delete temporary resources.
4. Check storage resources.
5. Check networking resources.
6. Verify that no unnecessary resources remain.

## Security and Cost

Unused resources increase both operational and security
risk.

Therefore, resource cleanup is part of the lab completion
process.
