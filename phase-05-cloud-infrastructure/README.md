## ⚖️ Security Principles

### Least Privilege
Grant only the permissions required for a task.

### Least Exposure
Expose only the services that need public access.

### Network Segmentation
Separate public-facing, application and database workloads.

### Credential Protection
Never store real credentials inside the repository.

### Backup and Recovery
Maintain backups and test restoration procedures.

### Cost Control
Stop or remove unnecessary cloud resources.
