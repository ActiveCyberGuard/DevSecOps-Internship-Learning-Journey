# Phase 3 — Docker & Containerization

## Overview

Phase 3 focused on Docker and containerization fundamentals,
secure image creation, multi-container application management,
and container security.

This phase covered:

- Container fundamentals
- Docker images and layers
- Containers vs Virtual Machines
- Docker container lifecycle
- Dockerfiles
- Secure image building
- Docker Compose
- Networks and volumes
- Healthchecks
- Container security
- Image hardening
- Vulnerability scanning with Trivy
- Secure containerized application delivery

---

## Learning Objectives

The main objective of this phase was to understand how
applications can be packaged, isolated, secured, and operated
using containers.

---

## Phase Structure

| Day | Topic | Main Focus |
