Terraform is an Infrastructure as Code (IaC) tool.

Terraform allows infrastructure to be defined using configuration files.

Important Terraform commands:

terraform init
terraform fmt
terraform validate
terraform plan
terraform apply
terraform show
terraform state list
terraform destroy

Terraform workflow:

Write Configuration
       ↓
terraform init
       ↓
terraform validate
       ↓
terraform plan
       ↓
terraform apply
       ↓
terraform state
       ↓
terraform destroy
