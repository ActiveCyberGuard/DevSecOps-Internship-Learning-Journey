# Day 37 — OWASP Top 10 and Threat Modeling

## Objectives
- Understand common web application security risks.
- Identify authentication, injection, access-control and configuration risks.
- Map threats to defensive controls.

## Tools
OWASP Top 10 guidance, Git, Markdown.

## Tasks
1. Identify assets and trust boundaries.
2. Document threat scenarios.
3. Select defensive controls.
4. Record a safe testing plan.

## Deliverables
- `docs/threat-model.md`
- `screenshots/`

## Result
A documented threat model that maps common risks to preventive and detective controls.

## Safety
Only test authorized applications. Never commit real credentials.
