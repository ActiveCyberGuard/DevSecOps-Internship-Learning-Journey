## Decision rules
1. Confirm the package and affected version.
2. Check a trusted advisory and fixed version.
3. Review breaking changes and application compatibility.
4. Upgrade, run tests, and rescan.
5. If temporarily accepted, record owner, rationale, compensating control and review date.

Do not leave example rows as confirmed findings.
