# Day 48 — Security Evidence Checklist

- [ ] Record exact image name and digest.
- [ ] Generate an SBOM using Syft or Trivy.
- [ ] Run a vulnerability scan and preserve actual output.
- [ ] Run Conftest policy checks against test manifests.
- [ ] Record tool versions and exact commands.
- [ ] Create a vulnerability register and remediation/exception log.
- [ ] Capture screenshots of actual results.
- [ ] Verify no credentials/private keys are staged.
- [ ] Review Git diff before committing.
- [ ] Confirm evidence matches the real tool output.
