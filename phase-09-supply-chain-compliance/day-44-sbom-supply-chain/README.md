# Day 44 — SBOM and Supply Chain

## Objectives
Generate and inspect an SBOM for a container image.

## Tools
Syft or Trivy, Docker.

## Deliverables
- `sbom/` generated JSON artifact(s)
- `docs/provenance-notes.md`
- `screenshots/`

## Security note
SBOM is component inventory, not a guarantee of security. Avoid including private metadata or credentials in artifacts.
